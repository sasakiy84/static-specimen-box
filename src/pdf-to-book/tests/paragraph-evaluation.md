# 段落結合と読み順の評価

## 横書き

添付PDF『「国会会議録」前史』の2、4、7、15、21、26、29ページを、埋め込み文字を優先して確認した。4、7ページはOCRのみでも確認した。4ページでは左段で始まる段落が右段の先頭につながり、罫線表の表題・出典、番号付き脚注がそれぞれ出力された。

## 縦書き

国立国会図書館所蔵の5資料から20コマを取得した。資料画像はIIIF Image APIで幅2,500 px、行の座標と読み順は次世代デジタルライブラリーの構造化テキストAPIを使った。小説、目次、教材、上下二段の見開きを含む。比較前の版は `3028ff9`。 [NDL APIの仕様](https://lab.ndl.go.jp/service/tsugidigi/apiinfo/)

| 資料 | PID | コマ |
| --- | --- | --- |
| 樋口一葉小説全集 第3巻 | 1133495 | 11、16、25、40 [資料](https://dl.ndl.go.jp/pid/1133495) |
| 吾輩は猫である | 1184660 | 12、19、30、42 [資料](https://dl.ndl.go.jp/pid/1184660) |
| 尋常小学国語読本漢字・熟語と其の応用 | 1444146 | 14、19、27、35 [資料](https://dl.ndl.go.jp/pid/1444146) |
| 図書寮典籍解題 第1 文学篇 | 2939220 | 23、31、34、42 [資料](https://dl.ndl.go.jp/pid/2939220) |
| 武士道 | 758906 | 12、21、27、38 [資料](https://dl.ndl.go.jp/pid/758906) |

NDLが本文とした縦書き行とアプリのOCR行を、座標の重なり（IoU 0.37以上）で一対一に対応づけた。アプリの出力内の位置を一意に特定できた行を集計した。読み順の評価では、両版で対応が取れた630行について、同じコマ内の行ペアがNDLの `ORDER` と同順かを調べた。段落境界の評価では、4コマの画像を見て49組に「同じ段落」「別の段落」を付け、両版で読めた36組を比較した。

| 指標 | 変更前 | 変更後 |
| --- | ---: | ---: |
| NDL参照と対応づけられた本文行 | 630 / 784 | 652 / 784 |
| 共通の行ペアの読み順がNDL参照と一致 | 15,109 / 15,247 | 15,247 / 15,247 |
| 目視で付けた段落境界と一致 | 27 / 36 | 32 / 36 |

『武士道』38コマ目では綴じ枠が図版に分類されて本文が出力されていなかった。修正後は参照23行のうち22行に対応が取れた。一方、『尋常小学国語読本漢字・熟語と其の応用』14コマ目には対応が取れた本文行がなかった。段落を短く区切りすぎる箇所も残る。読み順の一致率は、NDLが自動推定した順序との比較値であり、文字認識の正解率とは異なる。
